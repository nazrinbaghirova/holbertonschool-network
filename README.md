# holbertonschool-network

Networking projects from the Holberton School curriculum.

| Directory | What it covers |
| --------- | -------------- |
| `basics_0` | OSI model, types of network, MAC/IP addresses, TCP vs UDP, ports and ping |
| `basics_1` | localhost and `0.0.0.0`, `/etc/hosts`, listing interfaces, listening with netcat |
